# Security

This assistant runs in homes: it hears the room, reads mail and calendars, controls the smart
home and can make phone calls. Please report a vulnerability privately, not as a public issue:
on GitHub, **Security → Report a vulnerability** in this repository.

Helpful in a report: what an attacker can do, from where (the internet, the home network, a
device in the home, a message to the assistant), and the steps to reproduce it.

Only the current `main` is supported. Secrets (`local/`, `devices/echo/local/`) never belong
in the repository; if you find one in the history, report it the same way.
